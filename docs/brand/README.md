# Third-party logos

## alphaTab

[`alphatab-logo-horizontal.svg`](alphatab-logo-horizontal.svg) is the alphaTab logo, from the alphaTab maintainers (<https://github.com/CoderLine/alphaTab/discussions/1608#discussioncomment-10284905>).

- **Permission:** the maintainer allowed Smart Beat to use the alphaTab logo to credit and promote alphaTab, see <https://github.com/CoderLine/alphaTab/discussions/2930>. Tweaks for dark/light mode and sizes are fine.
- **Where to use it:** visibly, with the name and a link to <https://alphatab.net/>. The maintainer does not want the credit buried in a licence list or an about box, so it is in the README and on the app's start page (`src/components/built-with.tsx`), and goes on the website too.
- **Never** present Smart Beat as affiliated with, sponsored by or endorsed by alphaTab.
- If Smart Beat's commercial plans change, ask again (the permission was given for a free application).

Logos of other projects are not used here: plain names and links only, unless their owners allow more ([#82](https://github.com/mbalyi/smart-beat/issues/82)).
