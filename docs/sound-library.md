# The sound library: your own amps, pedals and cabinets (#41)

Users bring their own sounds; Smart Beat never ships or uploads them, because most free amp, pedal and cabinet captures do not allow redistribution inside software.

## What can be imported

- **Amp and pedal captures**: Neural Amp Modeler `.nam` files (WaveNet, LSTM and Slimmable models), run by [`nam-rs`](https://crates.io/crates/nam-rs) (MIT, pure Rust).
- **Cabinets**: impulse responses as `.wav` (mono or stereo, 16, 24 or 32 bit, any common sample rate). Stereo files are mixed to mono. Only the first 65 536 samples are used (1.4 s at 48 kHz); a longer file is imported with a note saying so.
- Files are limited to 64 MB. Four cabinets are generated by Smart Beat itself (nothing recorded is bundled).
- VST3 and CLAP plugin hosting is **not** part of this: it is tracked in its own issue.

## Where files go

Imports are copied into the app data folder (`library/`, named by a hash of the content, with `library.json` as the index). Nothing from the library is uploaded: the only thing the app sends over the network is the anonymous usage counters ([`analytics.md`](analytics.md); event names only, never sound or file names) and the update check. It has no file-system, HTTP or shell permission, and its content security policy only allows its own IPC channel. A test (`src-tauri/tests/library.rs`) pins that. Names and tags are the user's (renaming and tagging in the Sound library dialog, search and tag filter there too). Songs refer to captures by id, so a song opened on another computer shows "not in your sound library" for those blocks and plays without them.

## How a capture runs

- **Sample rate.** A capture only works at the rate it was recorded at. When the audio output runs at another rate (a 44.1 kHz capture on a 48 kHz output, or the reverse), Smart Beat converts to the capture's rate and back with a band-limited resampler (`src-tauri/src/audio/dsp/resample.rs`), a few samples of delay.
- **Level.** The capture runs on the mono mix of the track. After it a 5 Hz DC blocker removes any offset. "Match loudness" brings the capture to the level its own metadata says it was trained at (−18 dBFS RMS), so swapping amps does not jump. Input and output knobs turn without rebuilding the model.
- **Cabinets** are convolved with a partitioned FFT convolver (128 samples of delay) and resampled to the output rate with the same resampler.

## Bad files and crashes

- Import checks the file by building the model or decoding the WAV, and refuses with a reason: not a Neural Amp Modeler file, unsupported architecture, not a WAV file, silent or invalid samples, too large, unreadable.
- Nothing from a file runs on the audio thread until it was built successfully on another thread. If a block still panics while playing, the audio callback catches it (`Engine::render_guarded`): that buffer is silent, playback stops, every effect chain is bypassed and the app says "A sound stopped working". A poisoned engine lock is recovered the same way. Output is also checked for NaN and clamped.
- Tests: `src-tauri/src/audio/chain.rs` and `library.rs` (unit), `src-tauri/tests/library.rs` and `ipc.rs` (integration), `e2e/pedalboard.spec.ts` (browser). The test amp is a tiny made-up WaveNet with eight weights (no real capture).
