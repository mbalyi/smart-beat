# Cloud service logos

Official app logos of the cloud services Smart Beat can connect to. They are shown, unaltered
(no recolouring, distortion or restyling), next to the service name in the Open and Save chooser.
The files are only minified: editor metadata removed, numbers rounded, repeated paths shared.

Used only to identify the service the user connects; Smart Beat is not affiliated with or endorsed by these companies.

Retrieved on 2026-10-27 from Wikimedia Commons, which hosts the vendors' own artwork (the vendors
publish their brand kits as zip files).
